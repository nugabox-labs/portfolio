# portfolio

장누가의 개인 포트폴리오. [Akshayp2002/next-portfolio-new](https://github.com/Akshayp2002/next-portfolio-new)를 기반으로 이식했으며, 콘텐츠(소개/경력/학력/수상/프로젝트)는 Notion 데이터베이스를 원본으로 서버 사이드에서 조회해 렌더링한다.

아키텍처, 데이터 모델, 로컬 실행법, 배포 방법 등 상세 문서는 이후 단계에서 채워진다.

## Getting Started

```bash
npm install
npm run dev
```
